# 腾讯云语音输入接入

本文说明落地页 `/tax-ai` 和 `/tax-ai-pro` 的语音输入能力。

当前实现是“短语音转文字”：

```text
点击麦克风
-> 浏览器录音并编码为 16k 单声道 WAV
-> POST /api/ai/speech-to-text
-> 服务端调用腾讯云一句话识别 SentenceRecognition
-> 返回文字并填入输入框
-> 用户确认后手动发送给 Agent
```

## 为什么第一版使用一句话识别

腾讯云一句话识别适合 60 秒以内短音频，支持本地音频数据上传，接口域名为
`asr.tencentcloudapi.com`，接口名为 `SentenceRecognition`，版本为 `2019-06-14`。

第一版不做实时 WebSocket 的原因：

- 用户场景是“输入问题”，不是会议转写。
- 短语音识别接入更简单，出错面更小。
- 识别后先填入输入框，用户可确认文字，避免误发送。

## 腾讯云开通步骤

1. 登录腾讯云控制台。
2. 搜索并进入“语音识别 ASR”。
3. 开通语音识别服务。
4. 进入“访问管理 CAM”或“API 密钥管理”，创建 `SecretId` 和 `SecretKey`。
5. 确认账号有 ASR 调用权限，并确认账户余额或资源包可用。
6. 如需提升财税词汇识别率，可后续在 ASR 控制台创建热词表；第一版也支持临时热词。

官方文档：

- [腾讯云一句话识别](https://cloud.tencent.com/document/product/1093/35646)
- [腾讯云实时语音识别 WebSocket](https://cloud.tencent.com/document/product/1093/48982)

## 环境变量

本地 `.env.local` 或部署环境中添加：

```env
TENCENTCLOUD_SECRET_ID=你的SecretId
TENCENTCLOUD_SECRET_KEY=你的SecretKey
TENCENT_ASR_REGION=ap-shanghai
TENCENT_ASR_ENGINE=16k_zh
TENCENT_ASR_FILTER_MODAL=2
TENCENT_ASR_HOTWORD_LIST=发票|10,增值税|10,企业所得税|10,个税|10,社保|10,公积金|10
```

注意：

- `TENCENT_ASR_FILTER_MODAL=2` 表示严格过滤语气词；可改为 `1` 进行部分过滤，改为 `0` 不过滤。未配置或填写其他值时默认使用 `2`。

- 不要使用 `NEXT_PUBLIC_` 前缀。
- `SecretKey` 只能放服务端环境变量，不能出现在前端代码里。
- 修改环境变量后需要重启落地页服务。

## 本地测试

启动落地页后打开：

```text
http://127.0.0.1:3000/tax-ai
```

测试步骤：

1. 点击输入框左侧麦克风按钮。
2. 浏览器弹出麦克风授权时点击允许。
3. 说一句：“收到发票后应该怎么处理？”
4. 再次点击按钮结束录音。
5. 等待识别文字填入输入框。
6. 检查文字无误后点击发送。

如果提示“语音识别暂不可用”，优先检查：

- `.env.local` 是否配置 `TENCENTCLOUD_SECRET_ID` 和 `TENCENTCLOUD_SECRET_KEY`。
- 是否已开通腾讯云语音识别服务。
- 腾讯云账号是否欠费或资源包耗尽。
- 修改环境变量后是否重启了落地页。

## 后续升级

如果测试人员希望“边说边出字”，再升级腾讯云实时语音识别 WebSocket。届时建议仍通过后端生成签名或代理连接，不在浏览器暴露密钥。
