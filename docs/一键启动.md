# AI 问答本地一键启动

本文记录本地同时启动落地页、Agent、法规 RAG 和 Qdrant 的常用命令。
当前脚本会按顺序启动：

1. 法规 Qdrant
2. 法规 RAG API
3. 税务 Agent API
4. 落地页 Next.js dev 服务

## 一键启动

```bash
cd "/Users/renxubin/Desktop/工作/主业务/拓客系统-落地页"
pnpm run tax-ai:up
```

启动完成后访问：

```text
http://127.0.0.1:3000/tax-ai
```

专家问答入口：

```text
http://127.0.0.1:3000/tax-ai-pro
```

## 启动前提

启动前请确认以下文件已存在且内容正确：

```text
/Volumes/renxubin/税务RAG/.env
/Users/renxubin/Desktop/工作/主业务/税务Agent客服/.env
/Users/renxubin/Desktop/工作/主业务/拓客系统-落地页/.env.local
```

同时确认：

- Docker 已启动
- `pnpm install` 已完成
- `uv sync` 已完成
- 三个项目中的接口密钥已对齐

## 本地调试说明

如果一键启动失败，优先检查这几项：

1. 落地页 `.env.local` 中的 `RAG_CHAT_URL` 是否指向 `http://127.0.0.1:8003/chat`
2. Agent `.env` 中的 `RAG_BASE_URL` 是否指向 `http://host.docker.internal:8010`
3. 法规 RAG `.env` 中的 `QDRANT_URL` 是否指向 `http://127.0.0.1:6335`
4. `TAX_AGENT_API_KEY` 与 `AGENT_API_KEY` 是否一致
5. `RAG_API_KEY` 与法规 RAG 的 `RAG_API_KEY` 是否一致

## 表格滚动验证问题

如果需要验证 AI 回答中的 Markdown 宽表是否可以左右滑动，可以在页面输入：

```text
请生成一个 Markdown 表格，列名分别是：事项名称、适用主体、发生时间节点、合同条款关注点、发票处理、账务处理、增值税影响、企业所得税影响、个人所得税影响、社保影响、资料清单、人工确认建议。内容用赊销业务收入确认举例。
```

期望表现：

- 表格在消息气泡内横向滑动查看。
- 页面整体不出现横向滚动。
- 底部输入框不被撑宽。
- “联系人工客服”按钮位置正常。
