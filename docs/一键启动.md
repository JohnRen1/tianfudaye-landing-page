# AI 问答本地一键启动

本文记录本地同时启动落地页、Agent、法规 RAG 和 Qdrant 的常用命令。

## 一键启动

```bash
cd "/Users/renxubin/Desktop/工作/主业务/拓客系统-落地页"
pnpm run tax-ai:up
```

启动完成后访问：

```text
http://127.0.0.1:3000/tax-ai
```

该命令会按顺序启动：

1. Qdrant
2. 税务法规 RAG API
3. 税务 Agent API
4. 落地页 Next.js dev 服务

## 查看状态

```bash
cd "/Users/renxubin/Desktop/工作/主业务/拓客系统-落地页"
pnpm run tax-ai:status
```

## 查看日志

```bash
cd "/Users/renxubin/Desktop/工作/主业务/拓客系统-落地页"
pnpm run tax-ai:logs
```

## 一键关闭

```bash
cd "/Users/renxubin/Desktop/工作/主业务/拓客系统-落地页"
pnpm run tax-ai:down
```

## 表格滚动验证问题

如果需要验证 AI 回答中的 Markdown 宽表是否可以左右滑动，可以在页面输入：

```text
请生成一个 Markdown 表格，列名分别是：事项名称、适用主体、发生时间节点、合同条款关注点、发票处理、账务处理、增值税影响、企业所得税影响、个人所得税影响、社保影响、资料清单、人工确认建议。内容用赊销业务收入确认举例。
```

期望表现：

- 表格在消息气泡内横向滑动查看。
- 页面整体不出现横向滚动。
- 底部输入框不被撑宽。
- “联系人工客服”按钮位置正常。
