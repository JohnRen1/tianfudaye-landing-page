# 落地页初始读取状态

在缓存、身份、用户资料和业务数据尚未读取完成时，不展示未登录、零数量、未提交等业务结论。

- 首页与预约资料回填保留页面内容，PageLoadingState 在内容流中显示旋转圈和明确文案，让用户知道数据正在读取。
- 登录路由门卫等待时显示说明；跨页面时重新初始化，避免沿用上一页的放行状态。
- AI 问答恢复完成前隐藏快捷问题及未登录提示，发送操作沿用原有禁用逻辑。
- 资料中心顶部统计尚未知时显示 —，首次列表不显示空状态；刷新时保留已有条目。
- 签到与报告在身份恢复后读取数据，首次无数据时保留标题、返回入口和禁用的操作入口；已有内容刷新时保留内容，仅显示顶部加载圈。
- 投票使用真实配置，初始配置为 null；用户资料、问卷与已提交状态读取前不显示可提交表单。读取失败可重试。
- 我的报告身份未确认时显示提示而不是空报告；我的预约前往登录期间保持加载状态。
- 活动首页按地址参数重新初始化，防止切换入口时显示上个活动。

本次仅调整落地页初始展示和读取顺序，不修改管理后台、数据库结构或业务接口契约。登录网络失败的语义、请求统一重试、缓存刷新策略仍属于后续独立改进。

AI 问答在确认用户身份后先展示该用户的会话缓存，服务器校验完成前继续禁用发送。缓存不跨用户复用。

回归测试 initial-loading-state.test.ts 验证首屏保留首页内容、加载圈不占页面空间，同时没有默认问卷、假零值或提前显示的未登录提示。
人工验收建议使用慢网：逐一进入上述页面，确认只出现中性加载提示，读取成功后才展示真实状态；投票查询失败应展示错误与重试而非默认问卷。
